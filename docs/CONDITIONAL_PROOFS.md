`mkw_arm64::terminal::conditional::Effect` is a separate opaque conditional theorem. It can retain an existing local `NoReturn` fact, a checked same-image import assumption, or a complete control derivation under prior effects. An import assumption owns the exact source witness and provider theorem. Its requirements say which source thunk/slot must dynamically reach which exact provider source; they do not read the slot, authenticate its current value or discharge a runtime guard. There is no conversion from conditional evidence to unconditional `NoReturn`, and no metadata deserialization or name/boolean constructor. Contradictory provider sources for a shared slot refuse. Foreign images, duplicate/direct-self facts and excessive inputs refuse. This fingerprint is **not** codegen identity, a native build manifest, loaded-code authentication, target configuration or a runtime proof check. Those remain required before a compiler/runtime may consume these theorems.
